# Extensão Edge/Chrome — Salvar na Biblioteca

Primeira versão sem credenciais: ela apenas abre o site publicado, onde o login normal continua obrigatório, com URL e título pré-preenchidos como Artigo ou Vídeo.

1. Abra `chrome://extensions` ou `edge://extensions`.
2. Ative o modo do desenvolvedor.
3. Use **Carregar sem compactação** e selecione esta pasta.
4. Abra as opções da extensão e informe a URL HTTPS publicada do Sistema Pessoal.
5. Use o ícone ou o menu de contexto **Salvar no Sistema Pessoal**.

Nenhum token, senha ou conteúdo da sessão do site é lido pela extensão. O cadastro só é concluído depois da revisão e do clique em salvar dentro do app.
