# Sistema Pessoal — guia rápido para amigos

## O que é

O Sistema Pessoal é um espaço privado para organizar diferentes partes da vida
em uma única conta. Cada pessoa enxerga somente os próprios registros.

Hoje o site reúne:

- rotina de treino, academia e acompanhamento corporal;
- estudos, cursos, redações, ENEM e revisão;
- biblioteca de filmes, séries, animes, mangás, livros, podcasts, vídeos e artigos;
- agenda, projetos, programação, idiomas, histórico e diário;
- configurações de perfil, exportação dos próprios dados e suporte.

Alguns preenchimentos podem usar serviços externos, como Google, YouTube, TMDB,
AniList, Kitsu ou Jikan. Essas integrações são auxiliares: quando falham, o
cadastro manual continua disponível. Google Places está desativado para manter
o projeto gratuito.

## Como receber acesso

O piloto não tem cadastro público. Gabriel cria cada conta individualmente e
entrega uma senha temporária por conversa privada.

1. Abra <https://expansiondominionpersonaledition.vercel.app/login>.
2. Entre com seu e-mail e a senha temporária recebida.
3. Leia e aceite os Termos de uso apresentados no primeiro acesso.
4. Abra **Editar**, entre em **Alterar senha** e escolha uma senha pessoal com
   pelo menos 12 caracteres.
5. Não compartilhe a conta nem reutilize senha de outro serviço.

Se perder o acesso, fale diretamente com Gabriel pelo contato combinado. O
envio automático de recuperação para amigos ainda não é garantido neste piloto.

## Antes de usar

Este é um piloto gratuito e pode mudar ou ficar temporariamente indisponível.
Evite guardar a única cópia de algo importante. Leia o Aviso de privacidade e
não envie senhas, documentos de identidade, dados bancários ou informações de
terceiros em chamados de suporte.

Para relatar um problema, use **Perfil e configurações → Reportar um problema**
e retire informações pessoais do texto ou da imagem antes de enviar.

## Base para um vídeo curto de apresentação

Este guia também pode virar um protótipo de vídeo de 45–60 segundos:

1. “Sua rotina em um só lugar” — mostrar a página inicial;
2. mostrar rapidamente Treino, Estudos e Biblioteca;
3. mostrar Agenda, Projetos e Diário;
4. explicar que cada conta é privada e separada;
5. mostrar o primeiro acesso, o aceite dos termos e a troca da senha;
6. encerrar com “piloto gratuito para amigos, ainda em evolução”.

Uma ferramenta de IA pode criar storyboard, narração ou animação a partir
dessa sequência, mas capturas reais só devem usar dados fictícios e nunca
mostrar e-mail, agenda, diário, chaves ou informações pessoais.
